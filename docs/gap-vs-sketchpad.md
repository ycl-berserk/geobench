# 几何画板 vs geobench —— 功能测评

**日期**：2026-11-10
**对照对象**：几何画板（The Geometer's Sketchpad）5.x / 经典版
**目的**：找出我们在**功能**上还差什么，哪些是出题工作真正需要的，哪些只是"动态探究"的需要。

本文里的每一条都对着仓库核过（命令表、算子表、判定表、界面代码），不是凭印象。

---

## 一、结论先说

1. **内核上我们领先，而且是几何画板没有的东西**：它没有符号恒等判定，
   它的"检验关系"检查的是**当前这一张图**；我们有**恒等作用域** ——
   "对所有可行的摆放都成立"。这不是同一个东西。
2. **画图工具基本追平**，但缺一块**对象属性**：颜色、线型、隐藏、辅助对象。
   模型里全有，界面上一个入口都没有。**这一块直接决定图能不能进卷子。**
3. **几何画板领先的是"动态探究"**：参数滑块、动画、轨迹、迭代、自定义工具。
   这些对"出题"是次要的，对"探究"是主角。
4. **有一个便宜的缺口**：内核能查 **16 种关系**，界面上只给了 **7 个按钮**。
   比例相等、等角、点在圆上、切线…… 全是竞赛常用断言，按钮却按不出来。

### 6. 判定（几何画板没有对应物）

| 功能 | 几何画板 | geobench |
|---|---|---|
| 当前配置的检验 | 有（检验关系） | 有 |
| **恒等作用域**（对所有摆放都成立） | **无** | 有 |
| 未定义 / 退化情形 | 无明确语义 | 三态（ok / error / degraded） |
| 判定是否挡屏幕 | 挡 | 后台线程，不挡 |

**内核支持 16 种关系，界面只给了 7 个按钮**：
共线、共圆、等长、垂直、平行、外心、垂心。
内核还支持但界面没有：全等、相切、点在圆上、比例相等、等角、中点、角平分线、点与直线垂直、三线共点。

## 四、我们的强项（不要在追赶中丢掉）

- **恒等判定**：几何画板只能问"这张图里是不是这样"，我们能问"**永远**是不是这样"。
  这是命题工作台的命门 —— 一个反例能救一道题。
- **精确符号内核**：退化情形有明确语义（未定义 / 退化），不做"画出来像是对的"这种判断。
- **判定不挡屏幕**：后台线程跑，画布永远即时。
- **文件是人能读能改的**：DSL，而不是二进制。
- **名字对齐 GeoGebra 中文**，同时收英文名；教材和题库的叫法能对上。

---

## 五、建议的顺序

1. **对象属性**（隐藏 / 辅助线 / 颜色 / 线宽 / 标签）—— 模型的字段都在，缺的是界面。
2. **判定按钮补全到 16 种** —— 一晚上的事，收益最直接。
3. **双击精确输入坐标** —— **T032 已做**：双击一个点弹出两个框，输入的数字就是它的坐标（「1/2」和「0.5」是同一个数）。
4. **构造过程逐步播放** —— 几何画板最被惦记的功能，我们现在只有静态列表。
5. **自由数值 / 参数节点** —— 为滑块、动画、轨迹铺路；有了它，轨迹和迭代才可能做。

第 6 条之后的（轨迹、迭代、自定义工具、圆锥曲线）属于"探究"，不是"出题"。
在命题这条线上，前 5 条做完，我们和几何画板在**出题工作流**上就没有明显短板了。
