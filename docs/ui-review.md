# 界面评审：一个老师怎么用这张桌子

**用户不是"操作软件的人"，是正在备一道几何题的老师，或者正在看这道题的学生。**
界面上的每一个控件，都要能回答"他下一步要做什么"。这份文档按**教学流程**检查，
不按控件清单检查。

截图取自本机（1440×900，Windows），由 `QWidget.grab()` 直接抓取。

---

## 一、一条教学流程，五块界面

| 步骤 | 老师在做什么 | 界面应该给什么 |
|---|---|---|
| 1. 开始 | 心里有一道题，或者手里有一个 GeoGebra 文件 | 一个**起点**：示例、一句话、文件 |
| 2. 作图 | 把题目的条件摆出来 | 常用构造**伸手可及**，不是三层菜单 |
| 3. 提问 | "这三个点共线吗？""这两条线平行吗？" | **先选对象，再出现能问的问题** |
| 4. 看结果 | 想知道为什么，不成立时想看反例 | **一句人话 + 一眼能看到的反例** |
| 5. 出卷 | 图要进 Word / 讲义，颜色和标签要合适 | 每个对象的**外观**，导出即所见 |

## 二、本轮已经改掉的

### T051 · 判定面板按老师的问法重排

**之前**：17 个同样大的按钮平铺；点一个弹出一个"逐槽选对象"的对话框；
结论写 `不成立（refuted）`；证据是一串符号。

**现在**：

- 画布**有序多选**（点选、`Shift` 加选）；
- 选中对象后，面板只列**这些对象能问的关系**，点一下即加断言，**无弹框**；
- 全部 17 种折叠在"全部关系"里，没选中时仍可用；
- 说法用卷面语言：`A、M、B 共线`、`AM = MB`、`P 在 w 上`、`M 是 AB 的中点`；
- 结论是 `成立 / 不成立 / 不能判定`，第三列是 `对任意图形都成立` / `有一个反例`；
- 详情先给人话，**推导**折叠；
- **反例可以上图**：把自由点摆到反例位置，`Ctrl+Z` 回来。

### T052 · 第一屏

- 空画布中央有**三个入口**：打开示例 / 用一句话作图 / 打开文件；
- 文件对话框**认 `.ggb`**，导入时把"搬不过来的地方"逐条报告；
- 打开文件、导入、示例之后**自动适配视图**；
- 工具栏有**撤销 / 重做**和 `−` / `+`；
- 步骤栏的断言也用卷面语言，空图有提示。

### T053 · 点击交点就是交点

- 线·线、线·圆、圆·圆都算；**最近的**那个，不是第一个；
- 分支号与算子自己的编号一致（点右交点不会得到左交点）；
- 线段只算**画出来的部分**，延长线上的"交点"不算；
- 交点与光标距离 ≤ 对象距离 + 4 px 时建交点，沿对象走开就附着到对象。

## 三、还没改的（按对老师的影响排序）

### 1. 常用构造藏得太深（高）

**现象**：中点、交点、垂线、平行线都在组按钮的**第二层菜单**里；组按钮默认是组的第一个工具。
**为什么是问题**：这几样是每道题都要用的，老师每节课要点十几次。
**打算**：工具栏最前面加一个**"常用"组**（中点 · 交点 · 垂线 · 平行线 · 圆），
组菜单保持原样。验收：从打开到"中点"不超过 3 次点击。

### 2. 多选之后的问题列表太长（中）

**现象**：选 4 个点，"能问的"有 7 个（共圆、相等、全等、外心、垂心、重心、角平分线），
还是按命令表的顺序排。
**为什么是问题**：老师心里只有一个问题，列表太长等于没选。
**打算**：按**常用度**排序（共线/共圆/相等/平行/垂直优先），最多显示 6 个；
其余进"更多"。以及提示"再选一个点可以问共圆"。

### 3. 选择在步骤栏里不同步（中）

**现象**：多选 3 个对象，步骤栏只高亮最后一个。
**为什么是问题**：步骤栏是"这道题怎么造出来的"的记录，选中状态应该两边一致。
**打算**：`_on_selection` 里把多选映射成多行高亮。

### 4. 改外观要点五次（中）

**现象**：颜色、线宽、点大小、标签位置各是一个子菜单；隐藏/虚线/改标签还分散在别处。
**为什么是问题**：给一个点"标红、放大、标签放右边"是**一次**调整，不是三次。
**打算**：右键加一个**"属性…"**对话框，一页改完；子菜单保留给快速操作。

### 5. 读不到坐标（中）

**现象**：没有坐标轴和刻度；网格很密但不带数字。
**为什么是问题**：老师写题时要写"以 A 为原点"，学生要读"B(6,0)"。
**打算**：视图菜单加"显示坐标轴 / 刻度"；默认开细刻度、关箭头。

### 6. 字号偏小（中）

**现象**：界面 9.5pt。
**为什么是问题**：教室投影、老教师、大屏。
**打算**：设置里三档（紧凑 9.5 / 标准 10.5 / 大 11.5），默认标准。

### 7. 没有帮助入口（中低）

**现象**：菜单只有 文件 / 设置 / 编辑。
**为什么是问题**：老师第一次用，不知道 `Shift` 多选、`Ctrl+Z`、`Delete`。
**打算**：帮助菜单：快捷键一览、30 秒上手（就是那个示例）、关于。

### 8. 杂项（低）

- `Delete` 在多选时只删一个（应删全部或明确提示）；
- 步骤栏没有编号，播放时只有高亮，没有"第 3 步 / 共 9 步"；
- 断言在步骤栏不带结论颜色（右侧表格有）；
- 颜色只有 8 个命名色（自定义色要等需要时再说）；
- 导出对话框不显示纸面尺寸。

## 四、三条可以拿来检验的原则

1. **先有对象，再有动词**：选中的东西决定能做什么（判定面板已经是这样，工具栏还不是）。
2. **一个动作一次点击**：把"标红 + 放大 + 标签右移"当成一次属性编辑，而不是三次菜单。
3. **结论先于人话，人话先于符号**：表格给结论，详情给人话，推导折叠。

> 下一次改界面，先问一句：**老师此刻在做什么？** 答不上来的控件，就先不动。
