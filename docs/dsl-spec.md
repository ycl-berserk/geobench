# 中文几何 DSL —— 语法规格

**版本 0.1 · 状态：草案 · 本文是 `src/geobench/dsl/` 的唯一真源。**

DSL 的定位：**受限但确定**的中间语言。它不是自然语言，而是自然语言与构造图之间的一层薄翻译。

```
自然语言 ──(AI 翻译 或 人工)──▶ DSL ──(确定性解析器)──▶ 构造图 ──(确定性内核)──▶ 判定 / 渲染 / 成稿
   不确定                            受限确定                        确定性
```

- **DSL → 构造图永远确定性**：毫秒级、离线、零 API 成本、逐条可单测。
- **AI 只负责翻译**，且翻译结果必须过解析器校验；解析失败时错误带**精确行列**，供 Agent 重试。
- **DSL 是子集**：覆盖常用构造；覆盖不到的构造由 AI 翻译 + 人工兜底，并在此记录缺口。

---

## 1. 记号

| 记号 | 含义 |
|---|---|
| `A` `B` `P_1` | 对象名（点用大写字母；线/圆可用 `l1` `O1`） |
| `AB` | 以两个端点命名的**线段** |
| `l1` | 直线 |
| `⊙O` | 圆（圆心标为 `O`） |
| `△ABC` | 三角形（同时建立三条边 `AB` `BC` `CA`） |
| `(x, y)` | 坐标 |
| `⊥` `∥` `∩` `=` `≠` | 垂直 / 平行 / 交 / 相等 / 不等 |

## 2. 语句

一行一条。空行与行首缩进忽略。

### 2.1 声明自由点

```
点 A(0,0) B(4,0) C(2,4)
```

点的坐标是**数值摆放**；符号坐标由内核按名字生成（`x_A`/`y_A`）。

### 2.2 声明图元

```
△ABC                    # 三角形：建立线段 AB、BC、CA
线段 AB                  # 线段
直线 l1 = 过 A B         # 直线
⊙O = 过 A B C            # 过三点作圆
⊙O = 以 A 为圆心 半径 2   # 指定圆心与半径
```

### 2.3 构造

```
D = BC 上 A 的垂足
E = BC 中点
P = DE 与 ⊙O 的交点
Q = DE 与 ⊙O 的另一交点
I = △ABC 的内心
O = △ABC 的外心
H = △ABC 的垂心
G = △ABC 的重心
k = 过 A 的 BC 的垂线
m = 过 A 的 BC 的平行线
```

### 2.4 断言

```
断言 D E P 共线
断言 A B C D 共圆
断言 AB = AC
断言 AD ⊥ BC
断言 AB ∥ DE
```

断言写入构造图的 `relations`，由判定器裁定（§6 的双作用域）。

## 3. 构造子句 → 算子

| 子句 | 算子 |
|---|---|
| `XY 中点` | `point.midpoint` |
| `ℓ 上 P 的垂足` | `point.foot` |
| `ℓ₁ 与 ℓ₂ 的交点` | `point.intersect_lines` |
| `ℓ 与 ⊙O 的交点` / `另一交点` | `point.intersect_line_circle`（序号显式） |
| `⊙O₁ 与 ⊙O₂ 的交点` | `point.intersect_circles`（序号显式） |
| `△ABC 的内心 / 外心 / 垂心 / 重心` | `point.incenter` / `circumcenter` / `orthocenter` / `centroid` |
| `过 P 的 ℓ 的垂线 / 平行线` | `line.perpendicular_through` / `line.parallel_through` |
| `过 A B` | `line.free` |
| `过 A B C`（圆） | `circle.through` |
| `以 A 为圆心 半径 r` | `circle.free` |

### 3.1 交点序号的约定

直线与圆相交于两点时，序号按下式确定：

- **0 号** = 二次公式中取 `+√` 的那个根；**1 号** = 取 `−√` 的那个；
- **`另一交点`** = 那个**不是已知点**的交点（例如 `P = AD 与 ⊙O 的另一交点`，其中 A 已知在圆上）。

> "0 号 / 1 号"是**约定**，"另一交点"是**语义**。约定只影响画图与存储顺序，不影响几何；对拍也因此采用**集合比较**（见 `docs/decisions.md` D14）。
>
> 求"另一交点"时内核使用**代数捷径**（韦达定理的**两根之和**），**不出现根号、也不除以根号**——用符号化简比较两个根曾导致进程挂住 10 分钟以上。

## 4. 解析器契约

- **递归下降**，纯确定性，无副作用，无外部依赖。
- 错误类型 `DSLParseError(line, col, span, message)`：定位到行列与出错片段。
- **未识别的构造子句必须报错**，不得静默忽略或猜测。
- 解析产物是构造图（`spec.md` §3.1）。
- **往返一致**：构造图 → DSL → 构造图，节点集合与依赖关系一致（允许 id 重命名）。

## 5. 明确不支持（缺口清单）

这些是 DSL 当前的边界，超出即报错：

- 立体几何、圆锥曲线；
- 弧中点、切点、内切圆、旁心、外接圆（`circle.incircle` 等算子未实现）；
- 角平分线**点**（`point.angle_bisector_point`）；
- 带参数的变换（旋转、位似）；
- 多个自由点的自由坐标约束（`点 A` 之外的变量）。

> 这份清单是内核能力缺口的最真实来源：每加一条，对应的判定器与算子才有存在的理由。

## 6. 断言与判定

| DSL 断言 | 判定器 |
|---|---|
| `断言 X Y Z 共线` | `collinear` |
| `断言 X Y Z W 共圆` | `concyclic` |
| `断言 AB = CD` | `equal_length` |
| `断言 ℓ ⊥ m` | `perpendicular` |
| `断言 ℓ ∥ m` | `parallel`（v1.1） |

断言默认在 `identity` 作用域下裁定；要检查"这一张图"则用 `instance` 作用域（由调用方指定，DSL 不区分）。
