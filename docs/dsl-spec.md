# 中文几何 DSL —— 语法规格

**版本 0.2 · 状态：定稿 · 本文是 `src/geobench/dsl/` 的唯一真源。**

DSL 的定位：**受限但确定**的中间语言。它不是自然语言，而是自然语言与构造图之间的一层薄翻译。

```
自然语言 ──(AI 翻译 或 人工)──▶ DSL ──(确定性解析器)──▶ 构造图 ──(确定性内核)──▶ 判定 / 渲染 / 成稿
   不确定                            受限确定                        确定性
```

- **DSL → 构造图永远确定性**：毫秒级、离线、零 API 成本、逐条可单测。
- **AI 只负责翻译**，且翻译结果必须过解析器校验；解析失败时错误带**精确行列**，供 Agent 重试。
- **DSL 是子集**：覆盖常用构造；覆盖不到的构造由 AI 翻译 + 人工兜底，并在此记录缺口。

---

## 0. 语法风格：函数式，中文命令名（决策 D17）

DSL 用**函数式**，命令名取 **GeoGebra 的中文命令名**：

```
M = 中点(A,B)
```

**GeoGebra 的英文命令名同样接受**（`M=Midpoint(A,B)`），因为 GeoGebra 自己的输入栏在任何语言下都认英文 —— 老师在 GeoGebra 里怎么打，这里就怎么打，不必学第二套。

句子式（`BC 上 A 的垂足`）**已废弃**：它需要一套语法分析，而自然语言的理解本来就该交给 AI 那一层；DSL 的职责是**确定性地**解析，不该抢自然语言的活。

命令名与算子的对应关系由 `src/geobench/commands.py` 的**命令表**唯一决定；覆盖表见 [`plan.md`](plan.md) §6（由 `scripts/gen_coverage.py` 生成）。

## 1. 记号

| 记号 | 含义 |
|---|---|
| `A` `B` `P_1` | 对象名（点用大写字母；线/圆可用 `l1` `O1`） |
| `AB` | 以两个端点命名的**线段**（若已显式声明，则指声明的那条） |
| `△ABC` | 三角形（同时建立三条边 `AB` `BC` `CA`） |
| `(x, y)` | 坐标 |
| `,` | 参数分隔 |

> 圆**不带** `⊙` 前缀：命令式语法里，参数是**名字**，类型由算子的契约决定，不需要再标一遍。

## 2. 语句

一行一条。空行与行首缩进忽略；`#` 起注释。

### 2.1 声明自由点

```
点 A(0,0) B(4,0) C(2,4)
```

点的坐标是**数值摆放**；符号坐标由内核按名字生成（`x_A`/`y_A`）。英文写法 `Point A(0,0) B(4,0)` 等价。

### 2.2 声明图元

```
△ABC                # 三角形：建立线段 AB、BC、CA
AB = 线段(A,B)      # 线段
l1 = 直线(A,B)      # 直线
O = 外接圆(A,B,C)   # 过三点作圆
O = 圆(A,2)         # 以 A 为圆心、半径 2 的圆
```

### 2.3 构造

```
M = 中点(A,B)
D = 垂足(A,BC)
I = 内心(A,B,C)
O = 外心(A,B,C)
H = 垂心(A,B,C)
G = 重心(A,B,C)
k = 垂直(A,BC)
m = 平行(A,BC)
P = 交点(k,m)                    # 两直线
Q = 交点(AB,O,另一交点)          # 直线与圆
```

**重载由参数决定。** GeoGebra 允许同名命令有多种含义（`交点` 有三种，`圆` 有两种）；解析器按**参数的个数与类型**挑出唯一的那一个，挑不出来就报错。

### 2.4 断言

```
断言 共线(A,M,B)
断言 共圆(A,B,C,D)
断言 相等(AB,AC)
断言 垂直(k,m)
```

断言写入构造图的 `relations`，由判定器裁定（§6 的双作用域）。

> **线段可以直接写。** `断言 相等(AB,AC)` 说的是"A B 与 A C 等长"；判定器底层要的是四个点，所以解析器把线段**拆开**成端点。写法与卷面一致，底下不变。

## 3. 命令 → 算子

命令表在 `src/geobench/commands.py`（唯一真源）。下面是常用的一览：

| 命令 | 算子 |
|---|---|
| `中点(A,B)` | `point.midpoint` |
| `垂足(A,l)` | `point.foot` |
| `交点(l1,l2)` | `point.intersect_lines` |
| `交点(l,c,选择器)` | `point.intersect_line_circle` |
| `交点(c1,c2,选择器)` | `point.intersect_circles` |
| `内心/外心/垂心/重心(A,B,C)` | `point.incenter` / `circumcenter` / `orthocenter` / `centroid` |
| `垂直(A,l)` / `平行(A,l)` | `line.perpendicular_through` / `line.parallel_through` |
| `直线(A,B)` | `line.free` |
| `线段(A,B)` | `segment.free` |
| `外接圆(A,B,C)` | `circle.through` |
| `圆(A,r)` | `circle.free` |
| `共线/共圆/相等/垂直/相切/共点` | 判定器 `collinear` / `concyclic` / `equal_length` / `perpendicular` / `tangent_to` / `concurrency` |

### 3.1 交点序号的约定

直线与圆相交于两点时，序号按下式确定：

- **0 号** = 二次公式中取 `+√` 的那个根；**1 号** = 取 `−√` 的那个；
- **`另一交点`** = 那个**不是已知点**的交点（例如 `Q = 交点(AD,O,另一交点)`，其中 A 已知在圆上）。

> "0 号 / 1 号"是**约定**，"另一交点"是**语义**。约定只影响画图与存储顺序，不影响几何；对拍也因此采用**集合比较**（见 `docs/decisions.md` D14）。
>
> 求"另一交点"时内核使用**代数捷径**（韦达定理的**两根之和**），**不出现根号、也不除以根号**——用符号化简比较两个根曾导致进程挂住 10 分钟以上。

## 4. 解析器契约

- **递归下降**，纯确定性，无副作用，无外部依赖。
- 错误类型 `DSLParseError(line, col, span, message)`：定位到行列与出错片段。
- **未识别的命令必须报错**，不得静默忽略或猜测；**尚未实现的命令**报"尚未实现"，与"参数不对"分开。
- 解析产物是构造图（`spec.md` §3.1）。
- **往返一致**：构造图 → DSL → 构造图，节点集合与依赖关系一致（允许 id 重命名）。

## 5. 明确不支持（缺口清单）

这些是 DSL 当前的边界，超出即报错：

- 立体几何、圆锥曲线；
- 弧中点、切点、内切圆、旁心（`circle.incircle` 等算子未实现）；
- 角平分线**线**（`line.angle_bisector`）；
- 带参数的变换（旋转、位似）；
- 多个自由点的自由坐标约束（`点 A` 之外的变量）。

> 这份清单是内核能力缺口的最真实来源：每加一条，对应的判定器与算子才有存在的理由。
> 命令表里标着"未实现"的那些，就是这份清单的机器可读版本。

## 6. 断言与判定

| DSL 断言 | 判定器 |
|---|---|
| `断言 共线(X,Y,Z)` | `collinear` |
| `断言 共圆(X,Y,Z,W)` | `concyclic` |
| `断言 相等(AB,AC)` | `equal_length` |
| `断言 垂直(l,m)` | `perpendicular` |
| `断言 平行(l,m)` | `parallel`（未实现） |
| `断言 中点(M,A,B)` | `midpoint_of` |
| `断言 相切(l,c)` | `tangent_to` |

断言默认在 `identity` 作用域下裁定；要检查"这一张图"则用 `instance` 作用域（由调用方指定，DSL 不区分）。
