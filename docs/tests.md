# 测试地图：每一套在测什么，该跑多久

`pytest -q` 跑 996 个测试。**数量不是重点，重点是每一套在证明什么** ——
以及为什么它们必须跑得够快。

## 一套一张表

| 目录 | 数量 | 证明什么 | 预算 |
|---|---|---|---|
| `tests/unit` | 677 | **内核**：词法/语法、算子、判定器、精确算术、求值、模型、命令表 | ~55 s |
| `tests/oracle` | 5 | **每个算子都对着独立实现核过**：≥20 组构型，含退化；差集为空才能进注册表（spec §5.3） | ~70 s |
| `tests/eval` | 80 | **AI 通道**：契约用例 9 道、真实题面 22 道、录下来的答案过 CI 门禁 | ~15 s |
| `tests/property` | 19 | **性质**：编辑永远不会把图弄坏；DSL 往返一致 | ~3 s |
| `tests/contract` | 20 | **公开契约**：内核 API、MCP 工具的形状 | ~4 s |
| `tests/integration` | 9 | **端到端**：客户端/服务端一次完整会话 | ~33 s |
| `tests/perf` | 7 | **性能预算**：拖动一帧 3–7 ms | ~3 s |
| `tests/app` | 178 | **工作室**：工具栏、画布、撤销、导出、AI 面板 | ~7 s |
| `tests/no_float` | 2 | **精确性不变式**：内核里不许出现浮点字面量 | ~1 s |

两个「数量」值得解释：

- **`tests/unit/test_encoding.py` 一个文件就 489 项** —— 它对着仓库里**每一个文本文件**
  各跑一遍（合法 UTF-8 + 没有 `U+FFFD`）。每次几毫秒，但数量大。
- **`tests/oracle` 只有 5 个函数，里面是上千次比较** —— 每个算子一组夹具，
  夹具是「一堆构型 + 一个独立实现」。**它是最慢的一套，也是最值钱的一套**：
  「没有通过对拍的算子不得进注册表」全靠它。

## 为什么「跑得快」是产品问题

内核是**交互式**的：拖动一个点必须 3–7 ms 一帧（D18）。同一份代码，测试里慢 20 分钟，
就意味着用户手里也慢 20 分钟 —— 只是没人把秒表怼到他脸上。
T040b 的教训（化简预算按展开项数算）和 T043 的教训（对拍先比数再化简）
是同一件事：**慢不是"测试的问题"，是内核的问题**。

## 变慢了怎么办（按这个顺序查）

1. **先量**：`pytest --durations=20`，看**最慢的那几个**，不要猜。
2. **看它是不是在"数"上做符号工作**：两边都是数的时候，
   高精度数值比（12 位）就够，`simplify` / `radsimp` / `equals` 只当兜底（§11.5）。
3. **看它是不是没有预算**：展开、采样、判定都要有**上界**，超了就说"未证"（T040b）。
4. **再看是不是夹具太多**：一组夹具 ≥20 个构型是规格要求的，不能为了快而减。

## 两条命令：日常循环与完整门禁

```bash
pytest -m "not slow" -q     # 日常：约 2 分钟，991 个
pytest -q                   # 提交前 / CI：完整，约 3 分半，998 个
```

**标成 `slow` 的是「真的在算」的那 7 个**（恒等作用域的定理证明、以及直线与圆
"另一个交点"的符号求解），每个 5–40 秒。它们**仍然在 CI 里全跑** ——
`slow` 只是让**日常编辑**不必每次都等它们。

**为什么不直接删掉或缩小它们**：那 130 秒是产品的核心主张（判定要么精确、
要么诚实说没证），删掉等于把主张也删了。

## 一次真实的账（T043）

| | 时间 |
|---|---|
| T042 之前 | **~160 s** |
| T042 之后（切线带根号） | **1189 s** |
| 修完（先比数再化简） | **~200 s** |

罪魁祸首是**一个算子**（`line.tangent`，53 组夹具）：每一组要比较三条带根号的系数，
而比较的第一步是 `simplify`。**一个算子把整个套件拖慢了 10 倍。**

**还没做、但知道的**：集成测试每个都另起一个 MCP 服务进程（9 个测试 ≈ 40 s），
改成会话级复用能省 ~35 s。没做，是因为那要动测试骨架（跨测试共享 asyncio 会话），
风险与收益不划算 —— 记在这里，等它真的碍事再说。
