# 典型构型库

> 这份清单是**人写的资产**：AI 能保证构型成立，却保证不了"像不像竞赛题"。
> 竞赛生的直觉就是由这份清单养成的 —— 所以它必须由懂竞赛的人维护。
>
> 每条给出：构型名、构造链（用 §9 的 DSL 子句）、常用结论、常见考法。

标注：`[基准]` = 几乎每份卷子都会出现；`[常见]` = 高频；`[进阶]` = 联赛以上。

---

## 一、三角形的基本点（12 条）

| 构型 | 构造链 | 常用结论 |
|---|---|---|
| 内心 I `[基准]` | `I = △ABC 的内心` | 三条角平分线交点；到三边距离相等；`∠BIC = 90° + A/2` |
| 外心 O `[基准]` | `O = △ABC 的外心` | 三边中垂线交点；`OA=OB=OC`；圆心角 `∠BOC = 2A` |
| 垂心 H `[基准]` | `H = △ABC 的垂心` | 三条高交点；`∠BHC = 180° - A`；`AH = 2·OM` |
| 重心 G `[基准]` | `G = △ABC 的重心` | 三条中线交点；`AG:GD = 2:1`；`G` 把中线分成 2:1 |
| 三垂心（垂足） `[基准]` | `D = BC 上 A 的垂足` | 三个垂足共圆（九点圆）；`∠BDH = 90°` |
| 中点族 `[基准]` | `M = BC 中点` | 中位线平行且等长；重心在 `AG:GM = 2:1` 处 |
| 角平分线与垂足 `[常见]` | `D = BC 上 A 的平分线交点` | `BD:DC = AB:AC`（角平分线定理） |
| 旁心 `[常见]` | `I_a = △ABC 的 A 旁心` | 外角平分线交点；圆与一边相切、切另两边延长线 |
| 内心对称构造 `[常见]` | `P = BC 上 A 的平分线 ∩ ⊙(B, BA)` | 圆弧中点；`PB = PC = PI` |
| 等腰构造 `[基准]` | `D = BC 中点` 且 `AB = AC` | `AD ⊥ BC`；`∠B = ∠C`；三线合一 |
| 中位线 `[常见]` | `E = AB 中点`、`F = AC 中点` | `EF ∥ BC`，`EF = BC/2` |
| 中线三角形 `[常见]` | `M,N,P` 三边中点 | 中位线三角形与原三角形相似比 1:2，面积为 1:4 |

## 二、圆与幂（10 条）

| 构型 | 构造链 | 常用结论 |
|---|---|---|
| 点的幂 `[基准]` | `P = AB 延长线交点` | `PA·PB = PC·PD`（割线定理）；`PO² - R²` |
| 切线与弦 `[基准]` | `PT` 切 `⊙O` 于 T | `PT² = PA·PB`；`OT ⊥ PT` |
| 两圆公共弦（根轴） `[常见]` | `⊙O₁ ∩ ⊙O₂ = {M, N}` | `MN` 是根轴；`O₁O₂ ⊥ MN` |
| 圆内四边形 `[基准]` | `A,B,C,D` 共圆 | 对角互补：`∠A + ∠C = 180°`；`∠ABD = ∠ACD` |
| 圆内接四边形对角线 `[常见]` | `E = AC ∩ BD` | `EA·EC = EB·ED`；`∠AEB = ∠CED`（对顶） |
| 弦中点 `[常见]` | `M = 弦 AB 中点` | `OM ⊥ AB`；`MA² = R² - OM²` |
| 两圆内公切/外公切 `[进阶]` | 两圆 + 公切线 | 圆心距、切线长、夹角关系 |
| 圆内接三角形外接圆半径 `[基准]` | `R = 外接圆半径` | `R = a/(2 sin A)`；`a = 2R sin A` |
| 四点共圆的判定式 `[基准]` | 任意四点 | `∠APB = ∠AQB`（同弧）即可判定共圆 |
| 根轴与三圆 `[进阶]` | 三圆两两根轴 | 三根轴共点（根心） |

## 三、共线与共点（8 条）

| 构型 | 构造链 | 常用结论 |
|---|---|---|
| 梅涅劳斯 `[基准]` | `P,Q,R` 分别在三边上 | `(BP/PC)(CQ/QA)(AR/RB) = -1`（有向） |
| 塞瓦定理 `[基准]` | 三条 cevian 共点 | `(BD/DC)(CE/EA)(AF/FB) = 1` |
| 塞瓦逆定理 `[基准]` | 乘积为 1 | 三线共点 |
| 梅涅劳斯逆定理 `[常见]` | 乘积为 -1 | 三点共线 |
| 牛顿线 `[进阶]` | 完全四边形三对角点中点 | 三中点共线 |
| 达兰贝尔/西姆松线 `[进阶]` | P 在 `⊙O` 上，三垂足 | 三垂足共线（西姆松线） |
| 施泰纳线 `[进阶]` | P 在 `⊙O` 上，三反射点 | 三点共线 |
| 狄利克雷/拉格朗日 `[进阶]` | 四点 | 特殊共线族 |

## 四、完全四边形与射影（4 条）

| 构型 | 构造链 | 常用结论 |
|---|---|---|
| 完全四边形 `[进阶]` | 四点六线 | 三对角点共圆（圆锥曲线意义） |

## 五、相似与全等（6 条）

| 构型 | 构造链 | 常用结论 |
|---|---|---|
| 双垂直（半角模型） `[常见]` | `AD ⊥ BC`，`AE ⊥ AC` | `△ADE ∽ △ABC`；`AD/AE = AC/AB` |
| 角平分线 + 垂线双射 `[进阶]` | 角平分线上的点到两边距离相等 | 外心/内心构造统一模型 |
| 射影相似 `[常见]` | 旋转+位似复合 | 保角、保圆 |
| 蝴蝶形 `[常见]` | 中点 + 两条过点弦 | 中点连线被平分（蝴蝶定理） |
| 中位线 + 相似 `[基准]` | 中点 | 面积比、长度比 |
| 半角模型（等腰） `[基准]` | `∠A` 平分线 + 外接圆 | `DE = BE = CE` 等经典结论 |

## 六、等面积与比例（5 条）

| 构型 | 构造链 | 常用结论 |
|---|---|---|

## 用法约定

- 这份清单**不是**要全部实现的：v1 只覆盖第一、二、五、六节里能被判定器表达的部分。
- 每条构型在进入 DSL（T004）时，都会被翻译成"构造链 + 可判定关系"的形式；
  **翻译不出来的构型 = 判定器缺能力**，这是内核能力缺口的最真实清单。
- 新增构型的流程：先写构造链 → 写出一条该构型的判定关系 → 用 `geo_verify` 在
  `identity` 作用域下确认 `proved` → 才算入库。
