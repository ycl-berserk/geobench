# geobench 使用说明（竞赛几何版）

**这个程序用来把一道竞赛几何题的图做出来，并检查图上关于它的说法。**

不需要安装 Python，也不需要安装 GeoGebra。双击 `geobench.exe` 就能用。

---

## 一、第一次打开

1. 把整个 `geobench` 文件夹解压到一个你能找到的位置（**不要只把 exe 拖出来**，它旁边的 `_internal` 是程序的一部分）；
2. 双击 `geobench.exe`；
3. 如果 Windows 提示“已保护你的电脑”：点「更多信息」→「仍要运行」。程序没有买代码签名证书，这是正常提示；
4. 第一次打开是一张白纸，中间有三个入口：
   - **打开一个示例**：先看一遍“选中对象 → 提问 → 看反例”；
   - **用一句话作图**：需要先在「设置 → 模型服务」里配置；
   - **打开文件…**：打开 `.geobench` 或 GeoGebra 的 `.ggb`。

---

## 二、五分钟走一遍

1. 点「打开一个示例」；
2. 在图上**点一下 A**，再**按住 Shift 点 M、点 B**（三个点会高亮）；
3. 右边「判定」出现「共线」「中点」等按钮，点「共线」；
4. 表格里出现 `A、M、B 共线 · 成立 · 对任意图形都成立`；
5. 点一下这一行，下面会用一句话解释；点「推导」可以看代数。

### 看一个不成立的例子

1. 打开 `samples/03-九点圆.geobench`，或自己画一个；
2. 选中三个**不共线**的点，问「共线」；
3. 结论是 `不成立`，下面写「有一个反例」；
4. 点 **「在图上看看这个反例」**，图会摆成反例的样子；
5. `Ctrl+Z` 回到原来的样子。

### 改图的样子

- 右键一个点/线/圆 → **属性…**：标签、颜色、线宽、点大小、标签位置，一页改完；
- 右键 → **隐藏** / **虚线**；
- **蓝色的点是可以拖动的自由点，黑色的点是算出来的**（中点、交点、外心……），
  和 GeoGebra 一样；拖动自由点，图跟着动，松手后判定重算；
- 画布默认不显示坐标轴和网格，需要时在「视图 → 坐标轴」打开；
- 打开软件时默认是「选择」工具，不会在第一次点击时误放一个点；要画点先点工具栏「点」。

### 量角和证明角相等

- 工具栏「测量 → 角度」依次点三个点（**顶点在中间**），图上会在**这个顶点**
  画一段对应两边的小弧，并写 `∠CGO = 43.6°`；
- 选中六个点，按「第一个角的三点、第二个角的三点」的顺序（每个角顶点在中间），
  右侧会出现「角相等」，点它就会检查 `∠BPD = ∠BCA`；
- 判定为「成立」时，两个角上会画同款弧线记号；默认问的是“对任意图形是否成立”，
  只想看当前这张图，切到判定面板上方的「就这张图」。

### 图上的等长和直角

当一条「相等」或「垂直」被判定为**成立**时，图上会直接画出记号：
相等的线段上加短横线（第一组一条、第二组两条……），直角处画一个小方框。
记号只跟着“成立”的结论走；不成立或没判出来的说法不会画。

### 参数滑块

打开 `samples/02-参数滑块.geobench`，构造栏最上面有一条 `a` 的滑块：
拖它，圆的半径跟着变。`数 a = 2.5` 也可以直接写在文件里。

### 把图放进 Word

- `文件 → 导出 → 导出 PNG…`，然后在 Word 里粘贴；或
- `文件 → 导出 → 复制图形到剪贴板`，直接在 Word 里 `Ctrl+V`；
- 需要矢量图时导出 SVG。

## 三、文件

| 操作 | 说明 |
|---|---|
| `文件 → 新建` | 清空画板，重新开始（会先问要不要保存） |
| `文件 → 打开…` | `.geobench` 或 `.ggb`（GeoGebra 文件会翻译成我们的格式，搬不过来的地方会逐条说明） |
| `文件 → 最近打开` | 最近用过的几张图，点一下就能回去 |
| `文件 → 保存` | 图上的一切（构造、断言、外观、参数）都存进一个 `.geobench` 文本文件 |
| `文件 → 打开示例` | 一个能判定“成立”的三角形示例 |
| 导出 | SVG / PNG / 可拖动的 HTML（学生那边可以直接拖点）/ GeoGebra `.ggb` |
| 拖放 | 把 `.geobench` 或 `.ggb` 文件直接拖进窗口即可打开 |

**不会丢工作**：有未保存的改动时，标题栏会出现 `*`，关窗口会先问；
程序每几秒把当前图写到恢复文件，崩溃或断电后下次打开会问你要不要恢复。
确实不要了，选「不恢复」即可。

还有一些构造只能部分写回 GeoGebra（例如切线在 GeoGebra 里是两条）。
导出 `.ggb` 时会把写不回去的对象逐条列出来，不会悄悄改成别的图形。

**导入 `.ggb` 的方式**：按文件里的**构造顺序逐条翻译**，不是重新“猜”一张图。
GeoGebra 里隐藏的辅助线/辅助圆仍然保留（后面的构造要用它们），但**不会画在画布上**；
老师自制的工具（宏）按其定义展开，内部步骤也一并隐藏；对象颜色和虚线/实线也一并搬过来
（自由点仍蓝、派生点仍黑）；题目里的文字块会导入成画板上的文本，标签的显示/隐藏也保留。
搬不过来的构造会逐条说明。

## 四、键盘

| 键 | 作用 |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Delete` | 删除选中的对象（多选时一次删完） |
| `Shift + 点击` | 多选 |
| 左键拖空白 | 平移画布（选择工具下直接拖） |
| 中键拖动 | 平移画布（任何工具下都可用） |
| 滚轮 | 缩放；工具栏 `+` 放大、`−` 缩小 |
| 双击一个点 | 输入精确坐标（`1/2` 和 `0.5` 是同一个数） |
| `Ctrl+N` | 新建一张空白图 |
| `Ctrl+O` / `Ctrl+S` | 打开 / 保存 |

## 五、AI 作图（可选）

「设置 → 模型服务…」里选择一个 OpenAI 兼容的服务，填入接口地址、模型名和钥匙。
配置好后，在「AI 作图」里用一句话描述图形（例如“过 A 作 BC 的垂线，取它与 AB 的交点”），
程序会让模型写构造，再由**解析器**判断能不能画；画不出来会说明原因。

- **题目文字会发送到你配置的模型服务**，程序本身不保存对话；
- 不配置也能用：手动画图、示例、文件都不受影响；
- 没有网络时 AI 不可用，判定和作图不受影响。

## 六、目前不做 / 已知限制

- **圆锥曲线、轨迹/包络/参数曲线**：不在竞赛几何范围内，不做；
- **测量值暂时不能当参数**：`长度(AB)` 可以显示，但不能拿它当半径；请用 `数 a = …`；
- **特别大的图会拒绝判定**：精确层有预算，超出时图照样能画、能拖，但判定会写明“超出预算”；
- **导出 `.ggb` 是尽量写回**：圆锥曲线之外的常见构造能写回；写不回去的会列出来；
- **没有代码签名**：SmartScreen 会提示，点“仍要运行”。

---

## 七、遇到问题

请把下面两样发给我：

1. 出问题的 `.geobench` 文件（或那张 `.ggb`）；
2. 屏幕上显示的错误文字 / 截图；
3. 如果程序直接退出了，日志在 `%APPDATA%\geobench\geobench.log`，一并发来最好。

程序的界面字号可以在「设置 → 界面字号」里调大（紧凑 / 标准 / 大），投影时用“大”。
