# T061 交接前加固

**目标**：让真实老师能放心把一节课的图交给这个程序；把用户提供的四个
GeoGebra 文件全部读进来；补上“文件不会丢”的基本保证和 P1 功能。

## 完成

### GeoGebra 导入（真实语料）

- [x] `geogebra_macro.xml`：自定义工具按文件里的**定义展开**，不再按名字猜。
      `旁心`、`外心`、`垂心`、`垂线段` 等与内置同名的工具，以文件为准。
- [x] `Point(circle)`：读保存位置，反算成 `圆上的点(c, t)`，不再丢约束。
- [x] `Line(Point, Line)` → `平行`；`Midpoint(segment)` → `中点(A,B)`。
- [x] `PerpendicularSegment` → `垂足` + `线段` 两条命令，垂足可被后续对象依赖。
- [x] `Mirror(Point, Point)` → `点对称`（新增算子）。
- [x] 齐次坐标 `x/z, y/z`；`H'` / `H_{1}` 改名并记录。
- [x] 多输出命令（切线、多边形边）只导入第一个，其余逐条报告。
- [x] 依赖未导入对象的构造整体跳过并报告，绝不输出解析不了的 DSL。
- [x] **交点选择按源文件保存的位置校正**：GeoGebra 的“第 2 个交点”不一定是内核的
      `1`，直接照抄会让点跳到弦的另一端（Jacobbi 的 G 就是这样跑到了 E）。
      导入后做数值回放，用保存坐标挑真正那个交点，并迭代到依赖的交点也修正完；
      四个语料的全部 `Intersect` 点现在都与 `.ggb` 保存位置一致（误差 < 0.02）。
- [x] **批量账号语料**：Playwright 读取已登录会话，118 个资源中下载 115 个 `.ggb`；
      111 个可导入，4 个是工具包（空），3 个是 Classroom 链接。
- [x] 补 GeoGebra 的多输出/缺项：多边形边对象、两条线的角平分线、
      线/圆的镜像、第二条切线（`另一切线`）。`Polygon` 的边现在作为真实线段导入，
      依赖它们的交点/中点不再被连带跳过。
- [x] 四个真实 `.ggb` 全部导入、解析、求值通过；`tests/unit/test_ggb.py`
      里有一组“语料在就运行”的回归测试。

### 导入保真（反馈后修正）

- [x] 尊重 `.ggb` 的 `<show object="false">`：原文件隐藏的辅助线/点/圆
      仍然保留（依赖要用），但**不画在画布上**。
- [x] 宏内部步骤也隐藏，画布上只看到工具的**输出**，不是展开用的脚手架。
- [x] 导入后状态栏/提示框报告“翻译了多少、隐藏了多少、多少处调整”。
- [x] `角相等` 的参数顺序修正为**顶点在中间**（与 `角度(B,P,D)`、
      `_claim_text` 和纸面写法一致），并补了弧线记号、度数符号和示例
      `samples/04-角相等.geobench`。
- [x] 启动默认工具改为**选择**；工具栏图标再收到 **16 px**。
- [x] **自由点蓝色、派生点黑色**，标签保持黑色；屏幕 / SVG / HTML 一致。
- [x] 画布默认**隐藏坐标轴和网格**（视图菜单可打开）。
- [x] 作图区**所有工具**使用 **15 px 小箭头指针**（选择/画点/画线一致），不再用系统大十字。
- [x] **平移画布**：选择工具下左键拖空白即可平移，中键拖动仍然可用。
- [x] **缩放方向修正**：`+` 放大、`−` 缩小（原来 viewport 把 zoom 乘反了）。
- [x] **拖动限帧**：鼠标移动只记录最新位置，最多每 16 ms 计算一次，复杂图不再被鼠标事件淹没。
- [x] 首屏新增 **“从零开始画图”**：清空并直接切到点工具。
- [x] 点工具的交点识别扩大到 **12 px**，交叉磁吸 **8 px**；靠近线/圆交点不再误判成“线上的点”。
- [x] 作图反馈：鼠标进入点/交点的选中范围时画高亮圈；已经选为工具参数的点变成灰点 + 强调环。
- [x] **智能交点覆盖线段与射线**：线·线、线·圆、圆·圆都按“画出来的部分”判断；
      点在线段/射线上（不在交叉处）时附着，参数分别夹在 `[0,1]` 与 `[0,∞)`。
- [x] **右键框选**：选择工具下右键拖出矩形，选中区域内点/线/线段/射线/圆/多边形；
      线段、圆、多边形用解析判断，长线段穿过小框不会漏选；多选右键支持批量删除、
      颜色、隐藏、虚线。
- [x] **约束求解不再卡死**：40° 这类没有二次精确解的条件，原先用 20 个根号的 PSLQ
      可能跑几分钟；改成 3 维 PSLQ，约 1 秒明确拒绝；5-6-7 仍得到 `12*sqrt(6)/5`。
- [x] **判定面板改成“一句话”**：默认只留输入框 + 结果表；AI 只把中文翻译成关系
      （`interpret_claims`），对象与类型逐项校验后仍由本地精确内核判定。模型不可用时
      展开「手动选择」，旧的关系按钮/对象选择/问法仍在。
- [x] **AI 讲题 v1**：贴入题目 → 模型画图并拆 3–8 步 → 逐条 reveal/highlight/claim；
      内核核对每条几何事实，学生可追问并让教练补辅助线。协议与校验在
      `geobench/tutor.py`，课堂窗口在 `app/tutor_panel.py`，设计与竞品对照见
      `docs/tutor-design.md`。

      课时图形超过 80 个对象直接拒绝。
- [x] 非选择工具下**右键拖动 = 平移画布**（右键单击仍可打开对象菜单）。
- [x] “从零开始画图”后首屏卡片立即隐藏，不再盖在空白画布上。
- [x] 图标**绕画布中心**缩放，修正之前向右下偏的问题；测试量 glyph 包围盒。
- [x] 角度弧半径收到臂长 **12%**、细线 0.8，数字写成 `∠CGO = 43.6°` 放在弧外；
