# T057 —— 界面字号三档 + 帮助菜单

**状态**：已实现
**负责人**：Agent
**规格**：`docs/ui-review.md` §3.6–3.7
**依赖**：T024（设计系统）
**涉及层**：应用

## 问题

- 界面字号固定 **9.5pt**：教室投影、大屏、老教师都嫌小；
- 菜单只有 文件 / 编辑 / 视图 / 设置，**没有帮助**：第一次用的人不知道
  `Shift` 多选、`Ctrl+Z`、`Delete`。

## 做法

### ① 字号三档，当场生效并记住

- `theme.UI_SIZES`：紧凑 9.5 / **标准 10.5（默认）** / 大 12.0；
- `set_ui_size` 改全局字号，`apply_theme` 重新套字体、调色板、样式表
  （面板标题、空画布标题按比例缩放；间距不缩放——大字号配大间距只会浪费屏幕）；
- 反白区（推导）的等宽字体跟着变；
- 坐标刻度字号跟随界面字号（`QApplication.font()` × 0.72，下限 6pt）；
- `设置 → 界面字号` 三选一，**当场生效**；`QSettings("geobench","studio")` 记住，
  下次 `geobench-app` 启动时在 `apply_theme` 之前读回。

### ② 帮助菜单

- **快捷键…**：撤销/重做、Delete、Shift 多选、中键平移、滚轮缩放、双击精确坐标、
  打开/保存；
- **30 秒上手**：直接打开示例（拖动 A、右侧两条断言）；
- **关于 geobench**：版本、一句话定位、MIT。

## 验收

