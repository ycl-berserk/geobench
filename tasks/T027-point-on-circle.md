# T027 —— 圆上的点（贴点）

**状态**：已实现
**负责人**：Agent

**涉及层**：内核 · DSL · 应用

## 目标

用户原话：**我试图在一个圆上新建一个点，但是这个点是自由的，并不会只在圆上移动。现在的标点策略不够智能**。

## 做法

**贴点是一个构造，不是一个承诺。**

```
P = 圆上的点(ω, 1/4)
```

- 第二个参数是**位置**（按圈数计：0 是东，1/4 是北）；
- 它**进文件** —— 保存、重开之后约束还在；
- 点的坐标是**圆的符号的表达式** —— 所以 **判定器能证明**「P 在 ω 上」（恒等作用域下就成立）；
- 拖动改变的是**参数**，不是坐标 —— 所以它只能沿着圆走。

## 交付物

- 算子 `point.on_circle`（`圆上的点`）
- 新的节点角色 `attached`：有位置但**没有自己的坐标**
- 点工具落在圆上 → 造一个贴点（不是旁边的自由点）
- 拖动 → 改参数（按半度取整的精确有理数）
- DSL 写出/读入 `P = 圆上的点(w, 1/4)`
- 判定器：恒等作用域下证明「P 在 ω 上」
- oracle 电池：23 个夹具（20 正常 + 3 退化），独立推导的圆心
- 测试 `tests/app/test_on_circle.py`（5 个用例）
