# T031b —— 测量族：距离 / 长度 / 面积 / 周长 / 角度 / 半径 / 斜率 / 方向

**状态**：已实现
**负责人**：Agent
**规格**：[`docs/plan.md`](../docs/plan.md) §6
**依赖**：T029（多边形）、T028（圆族）
**涉及层**：算子 · 图元 · 渲染

## 目标

出题时老师要在图上写数字："AB = 5"、"∠A = 60°"、"面积 = 12"。这些数字是**关于**某个对象的，不是图形本身，所以要单独一种图元：**数** ✓。

## 交付物

- 新的图元种类 `number`
- 八个测度算子：
  | 算子 | 中文 | 量 |
  |---|---|---|
  | `measure.distance` | 距离 | 两点间 |
  | `measure.length` | 长度 | 线段 |
  | `measure.area` | 面积 | 多边形 |
  | `measure.perimeter` | 周长 | 多边形 |
  | `measure.angle` | 角度 | 顶角（**度**） |
  | `measure.radius` | 半径 | 圆 |
  | `measure.slope` | 斜率 | 直线 |
  | `measure.direction` | 方向 | 直线 |
- 各 27–31 组对拍夹具

## 关键做法

**角度用度，和 GeoGebra 一样。** 弧度算出来再换算（`acos(cos)·180/π`）✓。

**数不是形状，它写在被量的东西旁边。** 所以位置有讲究 ✓：

| 量什么 | 数字写在哪 |
|---|---|
| 距离、长度 | 线段的中点 |
| 角度 | 顶角 |
| 面积 | 多边形内部（形心） |
| 周长 | 多边形的一条边上 |
| 半径 | 圆的上方 |
| 斜率、方向 | 直线上离图形中心最近的点 |

面积写在里面、周长写在边上 —— 这样两个数**不会叠在一起** ✓。

**数字的写法也有讲究。** 整数就写整数（`6` 而不是 `6.00`），其余保留两位小数（`3.16`）✓ —— 多写几位既不更有用，也更难读 ✓。

**面积取正值。** 顶点写得顺时针还是逆时针，面积都是正的 ✓ —— 所以取绝对值 ✓（顺便也不必在乎叉积的符号 ✓）。

**直线的方向跟着它的定点走。** 一条直线 `ax+by+c=0` 写成 `ax+by+c=0` 还是 `-ax-by-c=0` 是同一条直线 ✓，可方向差半圈 ✓。所以方向取自**它是怎么画的**（第一个点到第二个点）✓ —— 这正是老师心里的那个方向 ✓。

**竖直线的斜率是"摆放"的退化，不是"构造"的退化。** 两个点不一定恒等于竖直 ✓，所以符号路径照常接受 ✓，数值路径把那个数标成 undefined ✓。
