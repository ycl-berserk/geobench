# T024 —— 把工作台做成一个"东西"，而不是一堆默认值

**状态**：已实现
**负责人**：Agent
**规格**：[`docs/plan.md`](../docs/plan.md) §M-B
**依赖**：T021c
**涉及层**：应用 · 判定

## 目标

用户原话：**"现在的界面太死板了"** ✓。

"死板"不只是难看：一个没有层级的界面里，**每一样东西看起来一样重要** ✓ —— 而这个工作台里的东西 importance 差别极大 ✓（构造步骤是骨架 ✓、判定结论是要给学生的答案 ✓、画布是草稿纸 ✓）。所以这一轮做的不是"加装饰"，是**把轻重分出来** ✓。

## 交付物

- **一套设计系统**（`app/theme.py`）✓：配色 ✓、间距刻度 ✓、圆角 ✓、字阶 ✓ —— 全在一个地方 ✓，改一次就是改全部 ✓
- **矢量图标**（`app/icons.py`）✓：**画出来的**，不是图片文件 ✓ —— 二进制文件没人能审 ✓，换个配色就过时 ✓
- **卡片式版面** ✓：三个面板各有卡片 ✓、标题条 ✓、一道强调色的小竖线 ✓
- **画布是一张纸** ✓：圆角 ✓、发丝边 ✓、极淡的网格 ✓、提示画成角上的便条 ✓
- **步骤列表是句子** ✓：名字是主语（深色加粗 ✓），调用是说明（灰字 ✓）✓
- **结论按它说的话上色** ✓：成立绿 ✓、不成立红 ✓、无法判定灰 ✓
- **作用域是二选一** ✓：两个按钮 ✓，而不是一个"切换作用域" ✓
- 顺手修的真问题：**判定器不接受线段** ✓（`垂直(m, AB)` 原来报"无法判定" ✓，契约说线段就该当线用 ✓）
- 屏幕上笔画不再细到看不见 ✓（纸面 0.4pt 是对的 ✓，屏幕不是纸 ✓）
- 门禁 `tests/app/test_look.py` ✓（7 个用例 ✓）

## 关键做法

**图标是画出来的。** 40 个图标，几十行 `QPainter` ✓。好处是：跟着配色走 ✓、任意尺寸清晰 ✓、进版本库 ✓、能被 review ✓。

**界面只有一种颜色。** 整个工作台**只有一种强调色** ✓（那道竖线、选中的按钮、成立的结论 ✓）—— 因为**屏幕上所有的颜色都应该属于图形** ✓，图形是黑白的 ✓，界面就该让开 ✓。

**"死板"的根是层级缺失。** 所以每个面板都有标题 ✓、标题说清这个面板干什么 ✓（"这张图是怎么造出来的" ✓、"哪些说法成立" ✓）。

**证据用等宽字体。** 证据是要一个符号一个符号读的 ✓，比例字体里减号和连字符一样宽 ✓，读者就不再相信排版 ✓。
