### F1 — 2026-11-09 · 判定器不接受线段

- **症状**：`垂直(m, AB)`（m 是直线、AB 是线段）返回"无法判定（undecided）"，证据里还夹着一句英文 `node 'AB' is not a line` ✓。
- **根因**：契约里"线"这一类**允许线段** ✓（"BC 上的垂足"对线段和直线是一个意思 ✓），算子也已经改成了 `as_line` ✓ —— 但**判定器还在用 `ctx.line()`** ✓，只认 kind == "line" ✓。
- **修法**：判定器里 7 处 `ctx.ctx.line(` 全改成 `as_line` ✓。
- **本该拦住它的门禁**：**没有** ✗ —— 判定器的测试都是拿直线测的 ✓ ✓。
- **动作**：**契约说"可以"的东西，三处都要真的收。** 改了算子忘了改判定器 ✓，就是同一个 bug 的第二只鞋 ✓。

### F2 — 2026-11-09 · 样式表把结论的颜色盖掉了

- **症状**：判定表里"成立（proved）"应该是绿的，实际是黑的 ✓。
- **根因**：样式表里写了 `QTableWidget::item { color: ...; }` ✓ —— 有样式表时，样式表的颜色**盖过**控件自己的 `ForegroundRole` ✓。
- **修法**：样式表不再写 item 的颜色 ✓；另外给应用设了 `QPalette` ✓（样式表管不到的地方，palette 接手 ✓）；结论的颜色用**自定义角色**传（字符串）✓ —— `QColor` 从模型里取回来是个 `QVariant` ✓，在 delegate 里拆它不如不去碰它 ✓。
- **动作**：**样式表是全局的** ✓ —— 它替每个控件做的决定，都是替具体控件做的决定 ✓。

### F3 — 2026-11-09 · 选中的行把结论的颜色丢了

- **症状**：改完 F2，未选中的行对了 ✓，**选中的行还是黑的** ✓。
- **根因**：选中态的文字颜色取自 palette 的 `HighlightedText` ✓ —— 逐项的 `ForegroundRole` 在选中时不管用 ✓。
- **修法**：判定表自己画文字 ✓（`VerdictDelegate` ✓）—— 颜色从模型里拿 ✓，选中与否都一样 ✓。
- **动作**：**要保留的东西，不能交给全局样式。**

### F4 — 2026-11-09 · 步骤列表的头没有加粗

- **症状**：两层颜色画出来了 ✓，但"名字"和"调用"一样粗 ✓。
- **根因**：delegate 画的时候用的是 `option.font` ✓，没设粗体 ✓。
- **动作**：**两种颜色 ≠ 两层。** 粗细也是层级的一部分 ✓。
