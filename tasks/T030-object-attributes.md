## 目标

和几何画板对比时最大的缺口，而且是**最便宜的一个**：

- 模型里每一个属性字段都在（`Style.visible`、`Style.line_style`）✓；
- 绘图层**已经**认它们（隐藏的对象不画，虚线的对象按辅助对象画）✓；
- 但**界面上没有任何入口**，而且**存不进文件** ✗。

竞赛图恰恰需要这两样：

- **辅助线**（高、垂直平分线、辅助圆）画成**虚线** —— 它支撑图形，
  但不属于题目本身；
- **脚手架隐藏** —— 画图时要看，印在纸上不该看。

## 做法

### 界面

**右键一个对象**，弹出 GeoGebra 的对象菜单：

```
显示 / 隐藏
实线 / 虚线
─────────
删除
```

（删除以前是"右键一个点 = 删掉它"，现在进了菜单 —— 误点一下就没了，
这在画板上是危险的。Delete 键仍然删选中的对象 ✓。）

### 文件

DSL 多两句话：

```
隐藏 l          这个对象不画
辅助 l          这个对象画成虚线
```

放在构造之后（它们说的是已经存在的对象）✓。读回来一样 ✓。
