# T033 —— 判定器补齐：平行 / 点在 / 比例 / 三个中心 / 角相等

**状态**：已实现
**负责人**：Agent
**规格**：[`docs/plan.md`](../docs/plan.md) §6；决策 D12、D15
**依赖**：T025
**涉及层**：判定器

## 目标

判定器是这个产品与"画图工具"的全部差别。所以它比算子更该先补齐。

## 交付物

新增 7 个判定器（9 → 16）：

| 判定器 | 中文 | 判据 |
|---|---|---|
| `parallel` | 平行 | 两直线的法向量成比例 |
| `point_in` | 点在 | 点在直线上 / 线段上 / 圆上 |
| `ratio_equal` | 比例相等 | `AB/CD = EF/GH`（长度平方 → 多项式） |
| `circumcenter_of` | 外心 | `OA = OB = OC` |
| `orthocenter_of` | 垂心 | `AH⊥BC`、`BH⊥AC`、`CH⊥AB` |
| `centroid_of` | 重心 | `3G = A + B + C` |
| `angle_equal` | 角相等 | `∠ABC = ∠DEF`（无向角） |

外加 `congruent`（全等）作为 `equal_length` 的**同义词** ✓（命令表里的 `alias_of` ✓，DSL 解析时自动指向同一个判定器 ✓）。

## 关键做法

**同时成立的多个等式 → 平方和。** "O 是 △ABC 的外心"是**两个**等式（OA=OB 且 OB=OC）。判定器只返回一个表达式，而实数域上**平方和为零 ⟺ 每一项都为零** ✓ —— 于是 `OA²−OB²` 与 `OB²−OC²` 的平方和就是那一个表达式 ✓✓。垂心同理（三条高）。

**角相等必须保住余弦的符号。** 无向角用余弦判定（余弦在 [0°,180°] 上单射 ✓）。如果把余弦**平方**，"∠B = ∠C"就会把**互补**的两个角也判成相等 ✗ —— 那是一个**假的"成立"** ✗✗，是这个产品最不能犯的错。所以宁可让边长带平方根（判定慢一点、可能落到"未证"），也不换一个更便宜但会说假话的判据 ✓。

**scope 要分清。** "两条画出来的直线平行"是**这张图**的性质（instance ✓）；"由 `平行` 命令作出的直线平行"才是**对一切摆放**成立（identity ✓）。测试里两种都写了 ✓。

**工具栏的关系按钮从命令表生成** ✓ —— 名字和"要几个对象"都取自表里，所以按钮不可能和判定器实际要的参数对不上 ✓。
