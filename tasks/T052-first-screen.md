# T052 —— 第一屏：空画布的三个入口、示例、打开就能看

**状态**：已实现
**负责人**：Agent
**规格**：`docs/spec.md` §10（导出与工作流）
**依赖**：T019（画布）、T034（`.ggb` 导入）、T050（外观）
**涉及层**：应用

## 问题

- 打开程序是**一张白纸 + 一行提示**：老师必须先学会工具栏，才看到任何图形；
- **`.ggb` 导入没有界面**：内核能读，但老师在应用里打不开 GeoGebra 文件；
- 打开文件后**不适配视图**：图在远处就只看到一角；
- 撤销/重做只在菜单和 `Ctrl+Z` 里；缩放只有滚轮。

## 做法

### ① 空画布是一个起点，不是终点

画布中央浮一张卡片（不挡画布：卡片外的点击仍然放点）：

- **打开一个示例**：三角形 + 中点 + 外心 + 外接圆，另加两条**会判成"成立"**的断言；
- **用一句话作图**：直接打开 AI 面板；
- **打开文件…**：`.geobench` 或 `.ggb`。

有图形之后卡片自动消失。

### ② `.ggb` 真的能打开

文件对话框增加 `*.ggb`；选择后走 `import_ggb`，把**搬不过来的地方**（一条切线变两条、
下标改名、浮点取整）用对话框逐条报告，而不是悄悄近似。`.ggb` 仍是 GeoGebra 的文件，
保存时写我们自己的格式，原文件不动。

### ③ 打开即适配

打开文件、导入 `.ggb`、打开示例之后都 `canvas.fit()`：先看到整张图，再决定放多大。
`fit_view` 同时读数值载荷和摆放，**图还在后台精确求值时也能适配**（不再要求精确坐标已就绪）。

### ④ 手边要有撤销和缩放

工具栏加**撤销 / 重做**（复用菜单的 action，不重复快捷键）和 `−` / `+`。
它们不替代快捷键，只是让不知道快捷键的人也找得到。
