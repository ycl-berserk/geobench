# T050 —— 图上卷面：颜色 / 线宽 / 点大小 / 标签位置

**状态**：已实现
**负责人**：Agent
**规格**：`docs/spec.md` §3.2（Style）、D6、D20
**依赖**：T030（隐藏 / 辅助线）、T045（改标签）
**涉及层**：模型 · 图元 · 渲染 · DSL · 应用

## 目标

一张图要能直接进卷子，最后一公里是**每对象的外观**：一道题里辅助线要虚线、
关键点要标红、圆可以画粗一点、标签要躲开线段。

模型里 `Node.style` 的字段（`color`、`line_width`、`point_size`、`label_pos`）
早就有，但：

- 渲染**完全不读** —— 屏幕和导出都只用全局 `FigureStyle`；
- DSL 只存 `visible` 和 `line_style`，颜色/线宽/标签位置**存不下来**；
- 界面没有入口。

## 做法

### ① 图元带“墨”

`Ink`（颜色 / 线宽 / 点大小 / 标签方位）挂在每个图元上，由 `Node.style` 填。
`None` 表示“跟全局样式走”。这样**一份原语、三个后端**（屏幕 / SVG / HTML）
自然一致。

- 屏幕：`QPen` / 点半径 / 标签颜色读 `Ink`，缺省回落到 `FigureStyle`；
- SVG：`stroke` / `stroke-width` / `r` / `fill` 同理；
- HTML：同一个图元列表，同样读 `Ink`；
- PNG 由 SVG 光栅化，不需要第四套实现。

**选中**时颜色被强调色覆盖（不是“再画一遍原色”）。

### ② DSL：四条属性语句

沿用已有的 `隐藏 A` / `辅助 l` 形状：

```
颜色 A 红
颜色 l 黑
线宽 l 粗
点大小 A 4
标签位置 A 右上
```

- 颜色是**名字**，不是 `#rrggbb` —— `#` 在 DSL 里是注释。八色：
  黑 / 红 / 蓝 / 绿 / 橙 / 紫 / 灰 / 棕（英文名同义）。
- 线宽：`细 / 中 / 粗` 或点数（0.25 / 0.4 / 0.7 pt）；
- 点大小：`小 / 中 / 大` 或像素半径；
- 标签位置：自动 / 右上 / 左上 / 右下 / 左下 / 上 / 下 / 左 / 右。
- `颜色 A 默认` 清掉覆盖，回到全局。

`to_dsl` 只写**非默认**的属性，顺序在构造之后、断言之前。

### ③ 界面：右键菜单

颜色 ▸ 八个色块（可勾选）；线宽 ▸ 细/中/粗；点大小 ▸ 小/中/大；
标签位置 ▸ 九个方位。全部走 `controller.set_*`，**可撤销**。

## 验收

```bash
pytest tests/unit/test_style_attributes.py -q     # 图元/渲染/往返
pytest tests/app/test_style_menu.py -q            # 右键菜单
pytest tests/app/test_export.py tests/integration/test_html_page.py -q
ruff check . && mypy src && scripts/gen_coverage.py --check
```

具体断言：

- 红色线段：屏幕 / SVG / HTML 三处都是这个颜色；
- 线的宽度覆盖只影响这一条线；
- `标签位置 A 右上` 让标签在右上象限；
- `to_dsl → parse` 之后样式逐字段相等；
- 属性可撤销；隐藏与颜色互不干扰。

## 非目标

- 渐变、透明度、自定义字体（不在“出题”这条线上）；
- 逐对象的箭头/线型（点线、点划线）—— 先做实线 / 虚线；
- 图例、背景色（属于版面，不属于对象）。
