# T036 —— 保存与打开：图形文件

**状态**：已实现
**负责人**：Agent
**规格**：[`docs/plan.md`](../docs/plan.md) §M-D
**依赖**：T024、T025
**涉及层**：应用

## 目标

一张存不下来的图，等于不存在 —— 老师关掉窗口，功夫就没了 ✓。

## 交付物

- **文件**菜单：打开… / 保存 / 另存为…（带快捷键 ✓）
- `StudioController.to_text()` / `load_text()` ✓
- 派生对象的**名字成为它的 id**（中点 M、外心 O…）✓ —— 于是名字能跟着文件一起活下来 ✓
- 测试文件 `tests/app/test_save_load.py`（3 个用例 ✓）

## 关键做法

**文件就是 DSL。** 自由点的位置、构造、断言，全在一段文字里 ✓ —— 老师能读、能改、能转手 ✓。不需要另发明一种文件格式 ✓。

**派生对象的名字要用 id，不能只是标签。** 原来 M 只是画在图上的一个标签 ✓，节点的 id 还是 "n1" ✓ —— 写文件时写的是 id ✓，所以名字**存不下来** ✓。改成**名字就是 id** ✓（中点 M、外心 O、内心 I、垂心 H ✓），文件里写 `M = 中点(A, B)` ✓，读回来还是 M ✓✓。

**坏文件要挡住，而且不能碰坏屏幕上的图。** 解析是严格的 ✓：不认识的命令、行列号 ✓。**先解析成功，再动图** ✓ —— 读不进去的文件一丁点都不改 ✓。

**坐标要能读。** 文件里的坐标保留 12 位有效数字 ✓（够精确 ✓），但步骤栏里只显示 4 位 ✓（够读 ✓）。

## 还没做的

- 打开文件时不做"要不要先保存" 的确认 ✓
- 没有 `.ggb` 的导入导出（那是 T034/T035 ✓）
