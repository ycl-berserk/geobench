## 问题

老师手里有大量 GeoGebra 课件（`.ggb`）。能直接打开，是采用率的关键 —— 否则
"换个软件"意味着"所有旧图重画一遍"。

## 做法

`.ggb` 是一个 ZIP，里面有 `geogebra.xml`；XML 把构造写成**按顺序的命令表**
（`Segment(A,B) -> f`），和 DSL 的形状**正好一样**（一行一条）。

所以导入是**翻译**，不是重新实现：每条命令变成同一构造的 DSL 行，
然后由**我们自己的解析器和内核**把图建出来。除了自由点的坐标，
不从 GeoGebra 读任何数字 —— 而那三个坐标也不原样信：它们是浮点数，
内核是精确的，所以每个都取成**六位有效数字的有理数**（`-1.63393` → `-163393/100000`）。

### 两个语言不一样的三个地方（每一处都会丢东西，所以都要说出来）

| | GeoGebra | 我们 | 处理 |
|---|---|---|---|
| 一条命令两个答案 | `Tangent(P, c)` 给**两条**切线 | 一条（取哪条是约定） | 导入第一条，**明确报告**第二条没进来 |
| 序号 | 交点从 **1** 数 | 从 **0** 数 | 在一个地方换算（`2` → `1`），有测试 |
| 名字 | `H_{1}`、`f_1` | 标识符 | 改名成 `H1`、`f1`，**报告改名** |

另外：`LineBisector(线段)` 要给成 `中垂线(A, B)`（我们收两个点）——
端点从那条 `Segment` 命令里取。

### 不能表达的，**报告**而不是近似

`不认识这两条对象的类型`、`参数个数不认识` —— 这些都进 `skipped` 列表。
**一张少了一个构造的图，是另一张图。**

## 实测（老师给的那张：`tkb80.ggb`，38 个元素 / 34 条命令）

- 3 个自由点（浮点 → 有理数）✓
- `Segment` / `Line` / `Midpoint` / `外心` / `垂心` / `Circle` / `Intersect` /
  `OrthogonalLine` / `LineBisector` ✓ **31 行 DSL**
- `Tangent(B, c)` 的两条 → 导入 1 条，**报告**另一条 ✓
- 7 个下标名改掉 ✓（`H_{1}` → `H1` …）

## 顺带修掉一个潜伏的 bug

DSL 的 `交点(直线, 圆, 1)` 原来**写不出来**：选择器只认中文词
（`第一交点`），不认数字 —— 而 **skill 里教的就是 `交点(c1, c2, 0)`** ✗。
是导入这张图时撞出来的。现在数字选择器可用 ✓（有测试）。

## 已知限制

- **只导入，不导出**。`.ggb` 的写出（含 GeoGebra 的样式、动画、脚本）没做。
- **不做 `Layer`/颜色/线宽**：几何进来，样式不进来。
- **两个答案只留一个**：`Tangent` 的第二条、没有选择器的 `Intersect` 的第二个交点，
  都只留第一个并报告。（要两条切线，需要给 `切线` 加"另一条"的写法 —— 记在 T042。）
- **精确求值可能很慢**：38 个对象、含多次圆与圆的交点，`evaluate_figure` 会跑很久
  （符号坐标爆炸）。这是 `evaluate_figure` **没有预算** —— 和 T040b 是同一类问题，
  另立任务，不在本次范围。
- **`geogebra.xml` 的旧格式**（format < 5）没测过。
