# T051 —— 判定面板按老师的问法重排（多选 → 提问 → 看反例）

**状态**：已实现
**负责人**：Agent
**规格**：`docs/spec.md` §6（判定双作用域）、D18
**依赖**：T033（17 个判定器）、T049（后台精确层）
**涉及层**：应用

## 问题

截图里最刺眼的一块：判定面板是**17 个同等大小的按钮**，先挑关系、再在弹框里逐个挑对象。
老师的实际顺序正好相反：

1. 在图上**指着**三个点；
2. 问"它们共线吗"；
3. 看到结论；不成立时，**看一眼**反例。

而且结论那一栏写的是 `不成立（refuted）`，证据是一串 `-(x_A + x_B)*(...)` ——
那是内核的语言，不是教室的语言。

## 做法

### ① 选择是一句话的主语

- 画布支持**有序多选**：点选替换，`Shift` 点选加入/移除；
- 选中 2–4 个对象后，判定面板只列**这些对象能问的关系**（槽位按种类匹配，
  顺序不对时自动找一种合适的顺序）；
- 点一下就加上断言，**没有弹框**；
- "全部关系"折叠保留：没有选中对象时，仍然可以直接挑一种。

### ② 结论是句子

| 以前 | 现在 |
|---|---|
| `共线` / `不成立（refuted）` / `-(x_A + x_B)*…` | `A、M、B 共线` / `不成立` / `有一个反例，选中可以看` |
| `相等(A, M, M, B)` | `AM = MB` |
| `作用域：identity` | `问法：证明`（对任意图形）/ `检验`（只看这张图） |

表格三列改成**说法 / 结论 / 为什么**；`equal_length`、`point_in`、`midpoint_of`、
`parallel`、`perpendicular`、`concurrency` 等都有卷面写法（`AB = CD`、`P 在 w 上`、
`M 是 AB 的中点`）。

### ③ 反例可以看

- 详情面板先给人话：这句话是什么、为什么成立/不成立、反例是哪几个点；
- **推导**折叠在后面（给想深究的人）；
- `在图上看看这个反例`：把自由点摆到反例的位置（一步撤销，`Ctrl+Z` 回来）。

## 验收

```bash
pytest tests/app/test_teaching_workflow.py -q
pytest tests/app -q
ruff check . && mypy src
```

6 项：三点选中出现"共线"、无弹框加断言、两线只给"平行/垂直"、
选不出一句话时说明原因、表格读成句子、反例能上图并能撤销。

## 非目标

- 拖动选择框、框选（下一步）；
- 多选后批量删除（现在 Delete 只在单选时生效）；
- 自定义断言的输入语法。
