# T056 —— 坐标轴与刻度（只在屏幕上）

**状态**：已实现
**负责人**：Agent
**规格**：`docs/ui-review.md` §3.5
**依赖**：T020b（画板网格）
**涉及层**：应用

## 问题

画布有网格，却没有数字：老师写"以 A 为原点"、学生读"B(6,0)"，都只能自己数格子。
网格在缩放很大时还会变成一片灰。

## 做法

- 画布绘制 x / y 轴（只画在视图范围内的那一条），轴上有刻度线和阿拉伯数字；
- **刻度步长** `_tick_step`：至少 64 像素一个标号，取 `1/2/5 × 10ⁿ` 的整数；
  普通适配时是整数（0,1,2…），放大很多才出现 0.5 / 0.2；
- 网格太密（< 14 px）时网格让路，**坐标轴和刻度仍然画**；
- 原点只写一次 `0`；
- `视图 → 坐标轴` 可开关，默认开；状态栏确认"坐标轴：显示/隐藏"；
- **导出不画坐标轴**：它是练习纸上的辅助，不是竞赛图的一部分。

## 验收

```bash
pytest tests/app/test_axes.py -q   # 3 项：步长、开关、轴上像素比网格深
pytest tests/app -q
ruff check . && mypy src
```

## 非目标

- 轴的箭头、边框、单位标签；
- 坐标读数随光标移动（"十字光标读数"是另一个功能）；
- 导出时可选坐标轴（等有人需要）。
