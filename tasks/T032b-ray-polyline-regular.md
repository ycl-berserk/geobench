# T032b —— 射线 / 折线 / 正多边形

**状态**：已实现
**负责人**：Agent
**规格**：[`docs/plan.md`](../docs/plan.md) §6
**依赖**：T029
**涉及层**：算子 · 图元 · 渲染

## 目标

三条"用现成零件就能拼出来"的命令 ✓ —— 不需要新概念 ✓，只要把**已有的图元**用对 ✓。

## 交付物

- `ray.free`（射线）：起点 + 方向点 ✓
- `polyline.free`（折线）：任意多个点 ✓，**不闭合** ✓
- `polygon.regular`（正多边形）：中心 + 一个顶点 + 边数 ✓
- 新图元 `RayPrimitive` ✓（两个后端都会画 ✓）

## 关键做法

**射线 = 直线 + 一个起点。** 直线原语是**无穷**的 ✓；射线是**半个**无穷 ✓ —— 所以它带**两个点** ✓（起点 ✓ 和方向点 ✓），两个后端各自把它裁到视口 ✓（`clip_ray` ✓：参数从 0 起 ✓，起点之前的那一半不算 ✓）。

**折线 = 不闭合的多边形。** 图元列表里就是**它的边** ✓（首尾相接 ✓，但最后一段**不连回去** ✓）。

**正多边形 = 转出来的顶点。** 顶点是把第一个顶点**绕中心转 360/n** ✓ ✓ —— 关键是**转得精确** ✓：sympy 会把 `cos(2πk/n)` 写成根式 ✓，所以正五边形带着 `sqrt(5)` ✓，正六边形带着 `sqrt(3)` ✓，而不是一串小数 ✓。

**正多边形是一个节点，不是 n 个。** 顶点是**算出来的** ✓，不是**点出来的** ✓ —— 所以它们不单独成为对象 ✓（GeoGebra 会为它们建点 ✓，我们是"一个多边形带着它的顶点" ✓）。代价是**引用不到单个顶点** ✓ —— 这是这次有意接受的 ✓。

## 顺手修的两个夹具问题

- `transform.mirror` 的随机夹具会取到**两个重合的点** ✓ → 那条线没有方向 ✓ → 对拍报"degenerate" ✓。
- 面积/周长的多边形夹具会**重复顶点** ✓ → sympy 把多边形化简掉 ✓ → 两边算的不是同一个东西 ✓。

现在多边形的夹具**互不相同的顶点** ✓，而且对拍里**重复顶点直接报错** ✓（不许悄悄过去 ✓）。
