# T058 —— 步骤栏：编号、一次删完、结论色

**状态**：已实现
**负责人**：Agent
**规格**：`docs/ui-review.md` §3.8
**依赖**：T020（构造步骤表）、T033（判定面板）
**涉及层**：应用

## 问题

- 多选三个对象按 `Delete`，什么也不发生（只有单选才删）；
- 步骤没有编号：说"第 3 步"时无从指认，播放时也只有一行高亮；
- 右侧判定表是绿/红，左侧步骤栏的断言仍然是灰色 —— 同一个结论，两种样子。

## 做法

### ① 多选删除是一次操作

- 画布：多选时按 `Delete` 发 `deleteManyRequested(list)`；
- `controller.remove_nodes(ids)`：合并所有依赖闭包，**只 push 一次 undo**，
  先删相关断言，再按依赖顺序删对象；
- 删完清空选择，状态栏说"删掉了 N 个对象（一次撤销可以全部找回）"；
- 单选路径不变（`remove_node` 现在只是 `remove_nodes([id])` 的简写）。

### ② 步骤编号

- 每一步前面有编号（`1 A (0,0)`、`4 M = 中点(A,B)`、`5 断言 A、M、B 共线`）；
- 断言接在构造之后继续编号：它是同一份"怎么造出来 + 断言了什么"的记录；
- 编号由 `NUMBER_ROLE` 交给 `StepDelegate` 单独画，`HEAD_ROLE` / `TAIL_ROLE` 不变
  （其他代码和测试仍按名字/调用读）。

### ③ 断言带结论色

- 判定回来后，`_tint_step_verdicts` 把每条断言染成 `PALETTE.ok` / `PALETTE.danger`
  （不能判定用 muted）；
- 悬停提示写清"断言：成立 / 不成立"和一句为什么；
- 图变了重建步骤时颜色自然清空，等新的判定回来再上色 —— 不保留过期结论。
