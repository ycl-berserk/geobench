### F1 — 2026-11-05 · sympy 1.14 的 `Line.intersection` 返回列表，不再返回 Point

- **任务**：T006
- **症状**：`point.intersect_lines` 的对拍全部失败，报 "lines do not intersect in a single point"。
- **根因**：`sympy.geometry.Line.intersection` 在 1.14 里返回 `list`，旧代码按单个 `Point` 判断。
- **修法**：过滤出 `Point` 实例，要求恰好一个。
- **本该拦住它的门禁**：`oracle`。
- **动作**：记一条原则：**对拍基准要按被测版本的实际 API 写，不能凭记忆**。

### F2 — 2026-11-05 · `Triangle.altitudes` 是 dict，不是 list

- **症状**：`point.orthocenter` 的对拍全部失败，报 `KeyError(0)`。
- **根因**：sympy 的 `altitudes` 是以顶点为键的字典；且返回的是**线段**，两段未必真的相交。
- **修法**：取字典的值，并先用 `Line(p1, p2)` 延长成整直线再求交。
- **本该拦住它的门禁**：`oracle`。

### F3 — 2026-11-05 · 退化夹具想当然：重心没有退化情形

- **症状**：`point.centroid` 的 4 组"退化"夹具全部报"kernel returned a value, expected a degenerate error"。
- **根因**：**重心对任意三点都有定义**，包括共线三点。我按"三角形类算子都会在共线时退化"套模板套错了。
- **修法**：引入 `edge`（反常但有定义）与 `degenerate`（无定义）两类夹具；`centroid` 改用 `edge`。
- **本该拦住它的门禁**：`oracle` 覆盖门禁。
- **动作**：覆盖规则改为"≥3 组非 normal"，且**只有声明了 `degenerate_when` 的算子才强制要求退化用例**。

### F4 — 2026-11-05 · `point.incenter` 在共线三点上没有报错

- **症状**：同上，但根因在内核而非夹具。
- **根因**：内心按边长加权平均，共线时公式仍有值。
- **修法**：显式检查面积二倍量为零则拒绝。
- **本该拦住它的门禁**：`oracle`。

### F5 — 2026-11-05 · 平行线夹具其实不平行

- **症状**：`point.intersect_lines` 的"平行线"退化夹具没有触发错误。
- **根因**：夹具用随机四点，`det` 恰好不为零。
- **修法**：专门构造平行夹具 —— 取一条线段，沿其法向平移得到第二条。
- **本该拦住它的门禁**：`oracle`。
- **动作**：夹具生成器里对"必须退化的情形"要**构造**出来，不能靠随机撞。

### F6 — 2026-11-05 · 根式表达式相等但 `simplify_to_zero` 判不出

- **症状**：`point.incenter` 对拍报"component 0 differs"，但两边数值相同
  （`(9 + 4√146)/(√146 + 16)` 与 `-4 + √146/2`）。
- **根因**：`simplify_to_zero` 的多项式判零只对 `QQ` 上的多项式有效，遇到 `√146` 就失效。
- **修法**：对拍比较时补一条 `radsimp(simplify(diff)) == 0` 的路径。
- **本该拦住它的门禁**：`oracle`。
- **动作**：这条只在**对拍**路径上补；内核的判定器仍走"采样 + 预算化简"，两条路径职责不同。

### F7 — 2026-11-05 · 线段算子没有对拍覆盖，覆盖门禁因此失败

- **症状**：`test_every_operator_has_a_full_fixture_battery` 报 `circle.free` 缺覆盖。
- **根因**：新增算子时忘了同步生成夹具与对拍实现。
- **修法**：为 `circle.free` 与 `segment.free` 补夹具与对拍；覆盖门禁继续保留。
- **本该拦住它的门禁**：`oracle` 覆盖门禁（本就是它该做的事）。
- **动作**：覆盖门禁**必须保留**，它正是"新算子不许绕过对拍"的执行者。
