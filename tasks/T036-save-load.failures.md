### F1 — 2026-11-08 · 名字存不下来

- **症状**：存盘再打开，中点不叫 M 了 ✓ —— 叫 n1 ✓。
- **根因**：M 只是节点上的一个**标签** ✓，节点的 **id** 仍然是 "n1" ✓。而写文件写的是 id ✓，读回来自然还是 n1 ✓ —— 标签**从来没进过文件** ✓。
- **修法**：让**名字成为 id** ✓（`construct` 时就把 id 定成 M ✓，重名就 M1、M2 ✓），文件里写 `M = 中点(A, B)` ✓，读回来还是 M ✓。
- **本该拦住它的门禁**：**没有** ✗ —— 是我自己写完往返测试才发现的 ✓（测试里专门断言了 "M" in after.nodes ✓ ✓）。
- **动作**：**"给人看的名字"和"存进文件的身份"最好是同一个东西。** 两个都要，就必然有一个会掉队 ✓。

### F3 — 2026-11-08 · 截图里看不到菜单栏

- **症状**：`window.grab()` 出来的图**没有菜单栏** ✓，只有工具栏 ✓。
- **根因**：Qt 的 `grab()` **不画 QMainWindow 的菜单栏** ✓（菜单栏由窗口边框那一层负责画 ✓）。
- **查法**：不猜 ✓ —— 打印几何：菜单栏在 (0, 0, 1180, 33) ✓，工具栏在 (0, 33) ✓，中央部件在 (0, 68) ✓ ✓ —— 布局是对的 ✓，截图只是没拍到 ✓。
