# T055 —— 属性对话框：一次改完，一次撤销

**状态**：已实现
**负责人**：Agent
**规格**：`docs/ui-review.md` §3.4
**依赖**：T050（每个对象的外观）
**涉及层**：应用

## 问题

给一个关键点"标红、放大、标签放右边"是**一个**意图，但要经过三个子菜单；
每次点击都是一步撤销。老师改完一处，撤销栈里多了三条。

## 做法

- 右键菜单最上面加 `属性…`，打开 `AppearanceDialog`：
  **标签文字、颜色（八色 + 默认）、线宽、点大小、标签位置**，一页改完；
- 点大小的组合框只在**点**上出现；线段的对话框没有点专属字段；
- 确定后调用 `controller.set_appearance(...)`：**先算出新样式，与旧样式比较，
  不同才 push 一次 undo**——没改就不留撤销记录；
- 外观只碰 `Style`：`coords` / `placement` 一个字节不动；
- 颜色子菜单、线宽子菜单保留，给"只改一个颜色"的快速操作。

## 验收

```bash
pytest tests/app/test_appearance_dialog.py -q   # 7 项：一次撤销、几何不动、无变化不撤销、回显、全字段、线段、菜单
pytest tests/app -q
ruff check . && mypy src
```

## 非目标

- 整张图的全局样式编辑（那是另一个对话框）。
