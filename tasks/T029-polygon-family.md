# T029 —— 多边形族：多边形

**状态**：已实现
**负责人**：Agent
**规格**：[`docs/plan.md`](../docs/plan.md) §6；决策 D20
**依赖**：T025
**涉及层**：算子 · 图元 · 渲染

## 目标

出题时"四边形 ABCD"是最常用的说法之一。它不该由老师手动画四条线段拼出来。

## 交付物

- `polygon.free`（多边形）：给定任意多个顶点，作出多边形
- 新的图元种类 `polygon`
- 变长参数（variadic）的算子契约
- 53 组对拍夹具（含 4 组退化）

## 关键做法

**多边形不是新形状，它就是它的边。** 所以多边形这个图元**带着顶点的坐标**，渲染时把相邻顶点连成线段 ✓。这样：

- 图里只有**一个**多边形对象，而不是"一个多边形 + 四条线段" ✓；
- 屏幕和导出画的是**同一批图元** ✓（决策 D20）—— 不存在"屏幕上是对的、导出的 SVG 里多了一圈线"的偏差 ✓。

**顶点个数不固定，所以契约要能说"任意多个"。** 给算子的最后一个参数加 `variadic` 标记 ✓：

```
polygon.free(a: point, b: point, c: point, ...: point[])
```

于是"三个顶点"和"四个顶点"是**同一个算子** ✓，而不是两个。仓库层和 DSL 层都要按这个规则算最少参数个数（必需参数 = 3，可变参数另算）✓。

**两个相邻顶点重合 → 报错。** 那会是一条长度为 0 的边，不是"退化但还能画"的东西 ✓。
