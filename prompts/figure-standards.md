# 竞赛几何作图规范

画一张竞赛图，和"能跑通"是两回事。下面是这张图应该长成什么样。

## 名字

| 对象 | 用什么名字 | 例 |
|---|---|---|
| 三角形顶点 | `A` `B` `C`（第二个三角形用 `D` `E` `F`） | `点 A(0,0) B(4,0) C(1,3)` |
| 外心 / 垂心 / 内心 / 重心 | `O` / `H` / `I` / `G` | `O = 外心(A,B,C)` |
| 边的中点 | `M` `N` `P`（第一个中点、第二个中点、第三个中点） | `M = 中点(B,C)` |
| 直线 | 小写 `l` `m` `k`，或 `AB` 这样的边名 | `l = 直线(A,B)` |
| 圆 | `ω`（也可 `c` `w`） | `w = 外接圆(A,B,C)` |
| 其它点 | 题面里怎么叫就怎么叫 | `P = 交点(l,m)` |

**名字要用题目里的名字**。题目说 P 就是 P，说 D 就是 D；不要自己发明 `point1`、`myLine` 这种名字 —— 老师拿到图要能直接对上题面。

## 画什么

- **三角形的边画成线段**，不是直线：`AB = 线段(A, B)`。竞赛图上的边就是线段。
- **只画题面提到的对象**，加上作图必须的那几个。多画的东西是噪音。
- **作图用的辅助线**（题目没提、但你得先做出来的那条）标成辅助：`辅助 l`。它在图上是虚线、且不参与标注。
- **不该出现的东西**写 `隐藏 l`。
- **圆上的点**用 `圆上的点(w, 1/4)`，参数是"沿圆周转的比例"（0 是起点，1/2 是对面）。

## 做得到的事，做不到的事

这个软件**做不到**的事，别画一张假图：

- **切线**：`t = 切线(P, c)` 要求 **P 在圆上**（先 `P = 圆上的点(c, 1/4)`）**或在圆外**。
  - P 在圆上 → 该点处的切线；
  - P 在圆外 → 从 P 引的切线（有两条，这个软件取其中一条，题面要"一条切线"时哪条都对）；
  - **P 在圆内 → 没有切线**（圆内一点引不出切线）。这种题面就说做不到。
- **两个圆的交点**要选一个：`P = 交点(c1, c2, 0)`。
- **参数里不能套命令**：先单独写一行。

## 参数的顺序（只有一条命令不是"一看就懂"）

**`角平分线(A, B, C)` 是 ∠ABC 的平分线 —— 顶点是第二个点**（和 GeoGebra 一样）。

所以「B 是顶点的平分线」要写 `角平分线(A, B, C)`，
「A 是顶点的平分线」要写 `角平分线(B, A, C)`。

**写反了不会报错**，只会画出一条不是题面要的那条线 —— 这是最危险的一类错。

## 坐标和构造：各管一半

题面的条件分两类，**用不同的手段去满足**：

### 一、长度：摆出来就行

要两条边长是整数、并且互相垂直，就**直接摆坐标** —— 这不需要算：

```
点 A(0,0) B(3,0) C(0,4)
```

`AB = 3`、`AC = 4`、`∠A = 90°` 同时成立。
**这是"摆"，不是"猜"** —— 摆出来的坐标就是它自己。

### 二、角度、关系：用构造去满足

```
点 A(0,0) B(5,0)
C = 旋转(B, 40, A)      # ∠BAC = 40°
E = 旋转(B, 60, A)
D = 位似(E, 3/5, A)     # AD = 3（E 的长度是 5）
M = 中点(B, C)          # M 是 BC 的中点
P = 圆上的点(w, 1/4)    # P 在圆 w 上
```

### 三、不要背坐标

**凭记忆套一组坐标（"稳的等腰三角形"之类）是不行的** —— 题面的条件一变，
那组坐标就不成立了。**图看着对，其实不满足题面**：这是最糟的一种错，
因为它既满足不了条件，又看不出错在哪。

### 四、坐标是精确的数

分数写 `1/2`，不要写 `0.5`。

## 结论

题目要"证明 …"的时候，**把结论写成断言**：

```
断言 共圆(D, E, F, P)
```

画板会拿判定器自己验一遍。你写错了，它会告诉你哪儿错了 —— 那比老师自己看出来强得多。

断言的名字要和判定器认的**一样**（见下面的命令表），参数是**对象的名字**，不是坐标。
