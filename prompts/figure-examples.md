# 范例

规则容易忘，例子不会。下面每个例子都是完整的、可用的作图代码。

## 例一：锐角三角形 + 外心、垂心、重心

```
点 A(2,3) B(0,0) C(5,0)
AB = 线段(A, B)
BC = 线段(B, C)
CA = 线段(C, A)
O = 外心(A, B, C)
H = 垂心(A, B, C)
G = 重心(A, B, C)
```

注意：`点`字写在**一行**的开头，后面可以跟好几个点。

## 例二：高的垂足 + 外接圆（九点圆那道题）

```
点 A(2,3) B(0,0) C(5,0)
D = 中点(B, C)
bc = 直线(B, C)
P = 垂足(A, bc)
ab = 直线(A, B)
ac = 直线(A, C)
de = 平行(D, ac)
df = 平行(D, ab)
E = 交点(de, ab)
F = 交点(df, ac)
断言 共圆(D, E, F, P)
```

## 例三：作一条切线

```
点 O(0,0) A(2,0)
w = 圆(O, A)
P = 圆上的点(w, 1/4)
t = 切线(P, w)
```

**圆上那一点处的切线** —— P 必须先在圆上。

```
点 O(0,0) A(2,0) P(4,0)
w = 圆(O, A)
t = 切线(P, w)
```

**从圆外一点引的切线**：P 在圆外就行。两条切线这个软件取其中一条，
题面只要"一条切线"时哪条都对。

**从圆内一点引切线是没有的** —— 那种题面就说做不到。

## 例四：作内心、角平分线

```
点 A(0,3) B(-2,0) C(2,0)
I = 内心(A, B, C)
m = 角平分线(B, A, C)
BC = 线段(B, C)
D = 交点(BC, m)
```

## 例五：圆上的点 + 三条连线

```
点 A(0,0) B(4,0) C(1,3)
w = 外接圆(A, B, C)
P = 圆上的点(w, 1/4)
PA = 线段(P, A)
PB = 线段(P, B)
PC = 线段(P, C)
```

## 常见的坑

- `A(0,0)` **不行**，要 `点 A(0,0)`。
- 命令的参数里**不能再套命令**。先单独写一行：
  ```
  l = 直线(A, B)
  P = 交点(l, 垂直(D, l))
  ```
  是**不行**的，要写成
  ```
  l = 直线(A, B)
  m = 垂直(D, l)
  P = 交点(l, m)
  ```
- `交点` 和 `圆` 都 overloaded：圆跟直线相交有两个交点，要用选择器（`0` 或 `1`）；圆跟圆相交也一样。
